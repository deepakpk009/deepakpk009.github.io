Frequently Asked Questions

What is TV Comic Book Reader? +

TV Comic Book Reader is an Android TV app for importing, browsing, and reading comic archives with remote-friendly controls.

Which comic formats are supported? +

The app supports CBZ, ZIP, CBR, RAR, CB7, 7Z, CBT, and TAR comic archives.

How can I add comics to the app? +

You can import comics with Web Import, WiFi Import, FTP Import, or by opening supported files shared from other apps.

Does Web Import need the same WiFi network? +

No. Web Import uses a temporary token and QR code, so it can work without sharing the same local network.

Does the app remember my progress? +

Yes. The app saves reading progress per comic and remembers view settings like zoom, rotation, night mode, and background color.

Can I browse pages visually? +

Yes. The app includes both a thumbnail-based comic library and a gallery or strip view for pages inside a comic.

Can I bookmark pages? +

Yes. You can bookmark pages, review bookmarks for the current comic, and browse all saved bookmarks from a dedicated screen.

Can I change the page display? +

Yes. You can zoom, change fit mode, rotate pages, enable night mode, and choose a custom background color.

Can I delete imported comics? +

Yes. Long-press a comic in the library for file actions such as viewing details or deleting imported files.

Is the app available in multiple languages? +

Yes. TV Comic Book Reader includes translations for many languages, including Arabic, Chinese, French, German, Hindi, Japanese, Korean, Portuguese, Russian, Spanish, Thai, Turkish, Vietnamese, and Indonesian.
